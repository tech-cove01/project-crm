# CRM-024b 只读取证范围与校准

第一个切片修复旧字段标签的范围判定。字段 ID 在去除显示标签后才校验，展示中的全角、半角和嵌套括号可共存。另识别有限的直接只读请求，例如只核当前金额和阶段且无需公司政策。已存旧任务可继续运行。报价、折扣和审批需求、含义不明的字段声明及作为旧备注转述的范围说明，仍走原政策路径。动作模式与发布源、真实缺证和持久复核保护沿用现有合同。

真实 S02/C01 标签、半角和换行、自然等价表达及政策需求的反例均进入定向用例。独立审查复现了附加计费或审计功能请求可能落入只核字段的错误，最终兼容路径逐句核对既有字段和展示约定，未知任务内容保留政策检查，显式排除政策也不能覆盖无效字段声明。原 CRM-023 的八题离线范围判定中 S02、C01、N01、N03 识别为只核字段，其余保持政策检查。协作执行和持久复核测试 46/46 通过，ESLint 和 diff 检查通过。这些是功能验证，实际两臂校准将在授权资料和第二个证据处理切片备好后执行。
