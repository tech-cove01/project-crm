## 原因和改动

原分路只取前六个有效词，候选页在标题、slug 或前 12000 字正文中合计匹配任意两个就可输出。F07 的词项已经含 SLA，却仅凭“正式/环境/承诺”通过；F08 缺少过期时间，F09 缺少每月订阅信息，也能凭客户/品牌和泛词通过。截断后部约束会加重问题，但不是唯一根因。

候选发现仍最多六词 OR、仅原查询零候选时每 KB 一次分路；输出前改为检查完整有界查询的有效词项，最多 32 个，必须全部在实际标题或前 12000 字正文中出现，slug 不作支持。查询超 2000 字符或词项超限时禁用分路，不静默丢掉末尾条件。通用疑问/请求套话被排除，没有按这三题、知识 ID 或领域属性加特判。原权限、发布页、来源文档、版本/哈希、15 秒截止和回执链保持。

这是保守的词面覆盖门禁，仍不能证明语义蕴含；否定句包含词项也可能通过，同义改写可能漏检。没有把“框架”硬映射到“架构”来隐藏已知退化。
