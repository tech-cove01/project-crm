# CRM-014s：明确演示的证据引用约定

日期：2026-10-28（Asia/Shanghai）。

对两次演示的结构化结果与当前 provenance 源码进行独立只读复核，发现父知识源/文档 ID 与实际片段/证据 ID、商机 ID 与 run_event ID 的身份混用可解释部分硬失败。另有批准后未重读商机导致的新阶段断言无法从已观察的读取事实验证；详尽诊断在 CRM-014b 的收尾材料记录，不能把这些检查当作语义正确率。

本切片只给固定任务增加输入约定：知识引用采用工具实际返回的片段/证据 ID，商机 ID 不冒充事件 ID，时间与其他观察值不自行拼造。没有修改运行时、权限、审批、评估实现、阈值或历史结果，语义尚需复核的状态仍应保留。

语法与 diff 检查通过，独立审查确认与现有 evidence provenance 契约一致。真实模型是否遵循新输入另在 CRM-014b 复现，不以提示词修改代替实测。
