# CRM-014t：三任务演示准备入口

日期：2026-10-28（Asia/Shanghai）。

`npm run demo:sales -- prepare --split` 生成 version 2 session，把客户确认事实、当次知识证据、商机审批拆成三个独立任务。客户段不判定未来触达同意，知识段不推演完整产品目录；真正读取失败仍需报告。商机段继续先提案、操作者批准后重读核对。旧默认 version 1 两任务与所有历史 session 保持兼容，已有 current 仍需显式 `--new`。

每段请求只含 API 接受的五个字段：客户段绑定联系人，知识段 scope 为空，商机段绑定原独立合成商机与漏斗。组织、合成标记、确认/同步记忆、来源授权、模型、未决任务及锁的原检查不变；不自动创建任务或批准业务。

22 项定向安全检查、两文件 ESLint、全仓 typecheck、语法/帮助与 diff 检查通过；独立审查通过，无重要发现。这些验证覆盖准备入口，三任务真实执行与 Langfuse 实际回读另行记录；不会把拆分提示词当作已解决模型稳定性。
