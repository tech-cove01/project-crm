## 投影和判分

补投影只读取当次匹配同调用 ID、同选定对象的真实回执。商机负责人、分配时间、标签、联系人邮件、电话及嵌套同意字段保留显式 null 与字段缺失的区别。合成标记从已有商机回执读取，批次标识省略。Wiki 权威只补到已校验的实际来源上。确认记忆的运行状态与完整程度分别保留，原答文、格式和业务真值沿用原版本。

真实空返回与待复核可以写进答复。原件完整且未交付必需事实或可用下一步时，必需项记失败。明确的数量、时限或政策错误只在补回的实际字段能证明同一断言时纠正。三项政策仍无法由原空检索核验，另有一项 CRM 状态缺少原观察，均位于已判失败的根内。H07 中断时缺失的工具回执依旧不可复核。

S 的 H11 单 Agent 经补回负责人和分配时间空值后判通过。C 的 H02 单 Agent 同样有明确空值，仍因把工作日人工支持写成唯一支持渠道失败。C 的 D04 三专家合成标记有据，但空组织记忆无法证明没有适用退款政策。C 的 H06 单 Agent 可以核验 Wiki 来源权威，180 天与六个自然月的期限断言仍无依据。
