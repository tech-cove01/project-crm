## 规划验收发现及定向修复

验收发现新审批分支在协作锁内从同一数据库连接池再次借连接。连接池上限为 1 时，Worker 会等待自己占用的连接。`34e55e1` 改为先持久化执行领取，再在协作锁内用同一个客户端复核提案、授权和租约。进入工具前锁超时记为已知未执行。进入工具后若效果不明，仍停在待对账状态。

审批、协作锁和本体工具三个定向测试文件共 33 项通过。新增回归禁止同一事务持有连接时再次借用，覆盖成功、授权撤销、调用前锁超时、调用后结果未知及再次领取防重复。TypeScript 和修改文件 ESLint 通过。上面的真实模型 Run 仍对应 `74b60c1`，定向修复未另发真实模型请求，原 Run 与计量保留。
