## 本轮规格：本机百炼 Agent 验收

- 接入百炼 OpenAI 兼容接口与旧项目 Qwen 模型；密钥仅存本机配置或 CRM 加密凭据，不能发送到其他供应商或写入 Git、输出和报告。
- 使用隔离的本地 CRM 环境和合成资料，经真实工作台 API、任务队列、Worker、模型与只读 CRM 工具执行一次任务，记录 Run、事件、结果及失败原因；明确实际计费和尚未验证的外部渠道边界。
- 小功能分别完成验证、审查、状态记录和提交；公网部署不在本轮。

## 本轮规格：CRM 核心能力验收

- 以当前本机 CRM、独立数据库和合成资料，分别核验客户记忆、组织知识库、Agent 审批及执行回执；对必须的模型请求使用已配置的百炼，禁止发送真实渠道消息。
