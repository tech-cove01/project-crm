销售跟进，
有依据也有回执。

Pi Native CRM 把商机、客户对话和企业资料放到同一条跟进流程里。Agent 查明事实并给出建议，销售负责人判断是否推进。动作执行后，系统重新读取实际状态，团队可以从结果回到最初的证据。

正式应用怎样运转

Web 处理交互，Worker 承接排队任务，SQL 保存业务事实和运行记录。

  1. Next.js

    Web 与 API

    接收请求，校验身份、角色和当前业务对象。

  2. Node.js

    队列与 Worker

    持久化任务，按租约领取并处理已获批的动作。

  3. Pi

    模型与工具

    通过许可的工具查询、取证、生成提案及回查。

  4. PostgreSQL

    业务事实与审计

    保存授权记录、确认记忆、审批与执行回执。
